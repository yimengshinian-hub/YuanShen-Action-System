# YuanShen-Action-System (类《原神》3D 动作系统)

基于 Unity 引擎独立实现的一套类《原神》风格的 3D 角色动作控制系统。项目采用自研分层状态机架构，实现了从输入、物理手感、动画同步到关卡管理的完整第三人称控制闭环。

## 🛠️ 技术栈
- **引擎版本**: Unity 2022.3.28f1c1
- **核心语言**: C# 
- **架构模式**: 分层有限状态机 (Hierarchical FSM) / 接口驱动 / 事件广播
- **输入系统**: Unity Input System (双通道: 连续值轮询 + 离散动作回调)
- **物理与相机**: Rigidbody 物理运动 / Cinemachine 虚拟相机

## ✨ 架构与核心技术点 (Highlights)

### 1. 自研分层状态机框架 (FSM)
- 通过 `IState` 接口定义 **10 个状态生命周期方法**，与 `MonoBehaviour` 解耦。
- **13 个角色状态**按“接地/空中/移动/停止/落地”组织为 **4 层继承树（6 个抽象基类）**。公共逻辑在基类，子类只覆写差异（模板方法模式）。
- **输入回调注册制**：状态在 `Enter` 注册、`Exit` 对称注销，形成状态级输入权限表；通过空覆写实现“家族级输入封禁”（例如 C 键主动翻滚时，封禁冲刺/刹车/落地共 7 个状态入口）。

### 2. 代码 FSM 与 Animator 双层同构联动
- Animator 的 Bool 参数分两组（**5 个组参数**管子状态机进出，**状态参数**管组内路由）。
- 一次性动作（如翻滚、冲刺、停止）由**动画事件帧**驱动退出，实现“动画播完才切状态、且支持即时打断”的流畅手感。
- 利用子状态机的默认态实现零冗余路由。

### 3. 物理手感与落地判定
- **Rigidbody 双 ForceMode 分工**：`VelocityChange` 用于速度校正（跟手），`Acceleration` 用于刹车指数衰减（丝滑）。
- **射线贴地系统** + 坡度速度曲线修正。
- **四档跳跃力度**（决策前置到起跳前状态）。
- **落地三分支判定**：根据坠落高度与移动状态，自动判定为轻落地、重落地僵直或翻滚卸力。

### 4. 深水 Bug 定位与修复记录
- **连按冲刺导致状态永久卡死**：定位到单帧动画事件被过渡混合吞掉且剪辑不重播，通过引入 `DashDuration` 超时兜底机制修复。
- **停止动画死锁**：定位到组参数缺失对称注销，通过在 `Exit` 补齐 `StopAnimation` 修复。

### 5. 状态变更事件与监视 HUD
- 在框架层实现 `event OnStateChanged` 状态变更广播，使得 UI/调试工具即插即用。
- 新增状态监视 HUD（显示当前状态、停留时间与状态流日志），实现新增调试界面**零状态类改动**。

## 📊 项目规模
- 包含 **58 个** 自研 C# 脚本。
- 接入 **13 段** 第三方角色动画，并手工完成事件帧标记。
- 实现完整第三人称控制闭环（含死亡、重生、检查点、通关结算 UI 联动）。

## 🚀 如何运行
1. 使用 Unity Hub 打开项目根目录（包含 Assets、Packages、ProjectSettings 的文件夹）。
2. 在 Project 窗口找到 `Assets/Scenes/SampleScene` 并双击加载。
3. 点击 Unity 编辑器顶部的 Play 按钮即可运行。
> 注意：项目需使用 Unity 2022.3.28f1c1 或兼容版本打开。
